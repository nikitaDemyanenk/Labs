Лабораторная работа №7: Многопоточность в Java
Описание

Данная работа посвящена изучению механизмов многопоточного программирования в Java. В ходе выполнения заданий освоены способы создания потоков через наследование класса Thread и реализацию интерфейса Runnable, механизмы синхронизации данных и использование высокоуровневых инструментов из пакета java.util.concurrent.
Ключевые концепции

Thread — базовый класс для создания и управления потоками

&nbsp;&nbsp;&nbsp;&nbsp;ExecutorService — сервис для управления пулом потоков и асинхронными задачами

&nbsp;&nbsp;&nbsp;&nbsp;Synchronized — модификатор для обеспечения потокобезопасности и исключения состояния гонки

&nbsp;&nbsp;&nbsp;&nbsp;Join — метод ожидания завершения работы потока

&nbsp;&nbsp;&nbsp;&nbsp;Semaphore — механизм ограничения доступа к ресурсу на основе счетчика разрешений

Содержание заданий

1 Многопоточное вычисление суммы элементов массива (Вариант 2)

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Реализована программа для быстрого суммирования больших массивов данных.

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Массив разделяется на равные части, каждая из которых обрабатывается отдельным потоком.

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Для управления потоками использован пул потоков ExecutorService. Итоговый результат собирается в главном потоке после завершения всех вычислений.

2 Поиск максимального элемента в матрице (Вариант 2)

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Разработан алгоритм параллельного поиска экстремумов в двумерных структурах данных.

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Матрица сегментируется на участки, которые передаются в ExecutorService для параллельной обработки.

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Главный поток сравнивает промежуточные результаты от каждого потока для нахождения глобального максимума.

3 Моделирование работы склада (Вариант с Semaphore)

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Реализована многопоточная модель логистического склада с участием 3 грузчиков.

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Ключевое ограничение: одновременная транспортировка партии товаров общим весом не более 150 кг.

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Использован Semaphore для контроля доступа к складу и управления весовым лимитом, обеспечивая синхронную отправку грузчиков на разгрузку при накоплении критической массы груза.
